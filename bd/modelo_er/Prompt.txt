## 3.3. Conexiones de Supabase

Quiero utilizar una configuración adecuada para Supabase PostgreSQL.

Revisa las opciones de conexión disponibles en Supabase:

- Conexión directa.
- Session Pooler.
- Transaction Pooler.

No asumas que todas son intercambiables.

Considera lo siguiente:

**Conexión directa:**
- Adecuada para conexiones persistentes cuando el entorno de red lo permite.
- Puede requerir IPv6, dependiendo de la configuración de Supabase.

**Session Pooler:**
- Alternativa para entornos IPv4.
- Mantiene una sesión de conexión.
- Puede utilizarse para aplicaciones que necesitan conexiones persistentes.

**Transaction Pooler:**
- Adecuado para aplicaciones serverless o entornos con conexiones de corta duración.
- Debe evaluarse su compatibilidad con las operaciones de Prisma.

Quiero que propongas una configuración que distinga:

- DATABASE_URL: conexión utilizada por Prisma Client durante la ejecución de la aplicación.
- DIRECT_URL: conexión directa o de sesión destinada a las operaciones de introspección y herramientas CLI, cuando corresponda.

La configuración debe adaptarse a la versión de Prisma instalada.

En Prisma 7, configura la URL utilizada por Prisma CLI en el archivo de configuración correspondiente. No utilices propiedades obsoletas como `directUrl` dentro de `schema.prisma`.

En Prisma 6, si se utiliza como alternativa, respeta su configuración específica.

No copies literalmente configuraciones de otra versión.

4. Un docente puede impartir diferentes asignaturas en diferentes programas académicos.
5. Cada grupo tiene un docente, una asignatura, un programa académico y un periodo.
6. Un alumno puede inscribirse a varias asignaturas simultáneamente.
7. Un alumno puede inscribirse como máximo a ocho asignaturas por periodo.
8. Un alumno no puede cursar dos veces la misma asignatura dentro del mismo periodo.
9. Cada inscripción puede tener una calificación final.
10. La calificación debe estar entre 0 y 10.
11. Debe conservarse el historial académico.
12. El promedio grupal debe calcularse a partir de las calificaciones finales de los alumnos inscritos.
